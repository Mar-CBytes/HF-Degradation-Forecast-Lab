Pipeline Stages

StageFileWhat it doesOutput
Ingest ingest.py Reads 32 monthly CSVs, normalises column names per-file, parses mixed tz-aware/naive timestamps, deduplicates on spot_id or timestamp+callsigns, converts Maidenhead grids to lat/lon wspr_unified.parquet
Label label.py Flags outage events per grid (gap >30 min, SNR <−28 dB sustained, or silence window). Sets future_outage_label=1 for pre-outage rows within 60-min horizon, excluding currently-outaged rows wspr_labeled.parquet
Features features.py 20 engineered features per spot including 4 new leading indicators: SNR slope, gap acceleration, spot rate trend, outage recency wspr_features.parquet
Split split.py Chronological 60/20/20 split — no shuffling to prevent data leakage. Train ≤ Jul 2025, Val ≤ Dec 2025, Test = 2026 train/val/test.parquet
Train train.py RandomUnderSampler reduces 26:1 imbalance to 10:1, then RandomForestClassifier (250 trees, depth 12, balanced weights). Threshold tuned on val set to maximise F1 rf_outage_model.pkl

Map UI Features

Interactive Map

  • Click anywhere to predict at that lat/lon
  • Heatmap overlay of risk across all known stations
  • Station markers with hover info
  • Zoom and pan globally

Prediction Panel

  • Grid square + coordinates
  • Risk badge — LOW / MEDIUM / HIGH
  • Outage probability % + progress bar
  • Next expected outage window
  • Confidence score (tree agreement)
  • Time offset slider (0–120 min look-ahead)
  • Known station dropdown

Model

  • Random Forest · 250 trees · depth 12
  • 10:1 undersampling (RandomUnderSampler)
  • Balanced class weights
  • Threshold tuned on validation set
  • 60/20/20 chronological split

Data

  • WSPR spots Jan 2024 – Aug 2026
  • 1.33M rows across 1,147 grid squares
  • Outage rate ~3.7% (future label)
  • Supports real + synthetic CSV formats
  • Auto column-name normalisation
